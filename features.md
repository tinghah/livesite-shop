# 'Great Wonder' Static Website Feature List

To make this static website feel dynamic and "impossible," I will implement the following features:

## 1. Visual Overhaul
- **Glassmorphism UI**: Using semi-transparent backgrounds with backdrop-blur for a modern, sleek feel.
- **Dark/Light Mode**: A seamless transition between themes that persists in local storage.
- **Bento Grid Layout**: For features and pricing, creating a structured yet dynamic visual hierarchy.
- **Custom Typography**: Using a combination of 'Inter' for body and a bold, expressive font for headings.

## 2. Advanced Animations (GSAP)
- **Smooth Scroll Reveal**: Elements will fade and slide into place as the user scrolls.
- **Magnetic Buttons**: Buttons that subtly follow the cursor when hovered, giving a high-end interactive feel.
- **Parallax Hero Section**: A multi-layered hero section that reacts to mouse movement.
- **Staggered Text Reveals**: Using GSAP's SplitText-like effects for headlines.

## 3. "Dynamic" Static Features
- **Interactive Pricing Toggle**: Switch between Monthly/Yearly pricing with smooth layout transitions.
- **Bilingual Content Switcher**: Instant language switching (EN/MY) without page reloads, using data attributes.
- **Floating Contact Widget**: A subtle, animated contact button that follows the user.
- **Live Preview Mockups**: Using CSS-only or high-quality image mockups of the resume sites.

## 4. Performance & SEO
- **Lightning Fast Load Times**: Optimized assets and minimal external dependencies.
- **Full SEO Meta Tags**: For better social sharing and search visibility.
- **Responsive Excellence**: Pixel-perfect layout from mobile to ultra-wide screens.
